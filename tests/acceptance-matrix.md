# Manual Acceptance Matrix

## Golden first-commit flow
Start Noob Mode → `git init` → modify `app.ts` → status → add → commit.

Verify X-Ray zones, realistic terminal, single graph node, main/HEAD pointer, concise beginner explanation and no duplicate-state glitches.

## Locale preservation
Create history + feature branch → EN→DE mid-session.

Verify hashes/branch/Graph/GitState/progress unchanged; UI/lesson/tutor switches to German; Git terminal output remains English.

## Conflict + AI showcase
Load conflict scenario → merge → conflict → ask tutor `Why is my repo like this?` → preview suggestion → run via normal engine.

Verify answer matches actual state, command is validated/risk-labeled, no direct AI mutation, preview matches execution and recovery is visually understandable.

## AI outage
Block provider/network. Verify tutor failure/retry, no crash, lab/lessons fully work.

## Mobile 390px
No page overflow; terminal input usable; lesson controls reachable; graph inspectable; AI becomes full-screen/sheet; language/mode controls reachable.

## Keyboard
Complete Beginner Lesson 2 without mouse. Verify focus, terminal history, dialogs and completion flow.
