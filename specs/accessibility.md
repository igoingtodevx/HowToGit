# Accessibility Contract

- Core beginner lessons keyboard-completable.
- Enter submits terminal commands; ArrowUp/Down history.
- Buttons/lesson items/commit nodes keyboard focusable.
- Visible focus indicators.
- Dialog/sheet focus trap and focus restoration.
- Escape closes dismissible overlays.
- Graph has textual summary such as `HEAD → feature at c123; feature is 2 commits ahead of main`.
- Branch/conflict/success state never encoded by color alone.
- `prefers-reduced-motion` respected without losing semantic feedback.
- Terminal output remains selectable/readable DOM text, not canvas-only.
