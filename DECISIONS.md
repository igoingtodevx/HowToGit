# Locked Decisions

1. Noob Mode is default.
2. English + German are first-class.
3. Git CLI syntax/output remains English.
4. One deterministic `GitState` is authoritative.
5. LLM is never engine/parser/validator.
6. Semantic effects drive animations.
7. Git X-Ray is the main beginner differentiator.
8. Git graph is in-house SVG.
9. Product works when AI provider fails.
10. Tests prioritize engine semantics over UI snapshots.
11. No backend/database for portfolio version.
12. No Tailwind/component framework.
13. Breadth yields before correctness/clarity.
14. Conceptual advanced modules are labeled honestly.
15. Locale switching never resets repo/progress.

## External dependency note

The requested AI endpoint/model is an external, fallible dependency. Keep endpoint/model configuration isolated behind a provider interface and make failure graceful.
